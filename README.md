# 손금 노트

손바닥 사진 위에 주요 손금을 직접 따라 그려 전통적인 의미를 살펴보는 모바일 웹앱입니다.

## 사용 방법

사진 선택 → 손금 선택 → 사진 위에 선 그리기 → 손금 해석 보기.

사진 회전, 선 수정, 전체 결과 복사를 지원합니다. 사진은 기기 안에서 처리하며 서버로 전송하거나 저장하지 않습니다.

## 구현 범위

자동 AI 손금 인식은 포함되지 않습니다. 사용자가 그린 선의 길이와 굽음을 측정해 전통적 상징을 안내합니다. 손금 해석은 재미용이며 성격, 건강, 수명, 재산, 미래를 예측하지 않습니다.

## 실행

index.html을 브라우저에서 열거나 정적 웹 호스팅에 게시하세요.

- index.html: 화면
- style.css: 모바일·데스크톱 스타일
- app.js: 사진 처리, 손금 그리기, 선 측정과 결과 복사
